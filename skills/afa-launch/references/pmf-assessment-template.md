# PMF 仪表盘模板 + 评分细则

> 本文档为 `afa-launch` 的参考文件，提供 Product-Market Fit 评估的完整仪表盘模板和评分方法论。
> **真源对齐**：本文件的维度、权重与计算口径以 `SKILL.md` 模式 C 与 `work-modes-and-templates.md` §1.2 的四维体系为唯一真源（客户痛点匹配度 25% / 支付意愿 25% / 产品体验满意度 30% / 竞争空间 20%），三处必须保持一致。
> **渲染规则**：本文件的评分档、信号强度与 Scale/Pivot/Kill 判断，默认只可作为阶段性参考与保守起点，不写成统一健康线或对品牌结果的确定性承诺；各维度打分结合样本量、品类特征与自有历史解释，不设跨品牌统一硬阈值。

```text

│                                                             │
│  综合 PMF 得分：[XX] / 100                                  │
│  信号强度：[强 / 中 / 弱 / 无]                              │

│  ├────────────────┼──────────┼──────────┼──────────┤        │
│  │ 总计           │ [XX]/100 │  100%    │  [XX]    │        │

└─────────────────────────────────────────────────────────────┘
```

**PMF Score 计算口径**（与 `SKILL.md` / `work-modes-and-templates.md` §1.2 一致）：

```text
按各维度满分（25 / 25 / 30 / 20）直接累加：
  PMF Score(0-100) = 客户痛点匹配度 + 支付意愿 + 产品体验满意度 + 竞争空间

若改用 0-10 制逐维打分，则等价换算：
  PMF Score(0-10) = 维度1×0.25 + 维度2×0.25 + 维度3×0.30 + 维度4×0.20
  （×10 即得 0-100 口径，两种表达等价）
```

## 二、四维评分细则

> 各维度按 0 至该维度满分打分；下表为定性锚点，实际取值需结合样本量、品类特征与自有历史解释，不作为跨品牌统一硬阈值。

### 2.1 客户痛点匹配度（25 分，权重 25%）

| 得分档 | 定性判断 | 参考观察信号 |
|------|----------|------|
| 20-25 | 多数有效样本主动提及相近核心痛点 | 用户访谈 / 评价 / 搜索词中痛点高度一致，主动提及率高 |
| 14-19 | 有明显共性痛点，但集中度一般 | 痛点方向清晰，但表述与优先级存在分歧 |
| 8-13 | 痛点分散或表达不稳定 | 需引导才提及，缺少自发共识 |
| 0-7 | 缺少稳定且一致的核心痛点 | 样本各说各话，无法收敛出主痛点 |

### 2.2 支付意愿（25 分，权重 25%）

| 得分档 | 定性判断 | 参考观察信号 |
|------|----------|------|
| 20-25 | 有效样本中出现较强购买意愿或明确支付信号 | 目标价格带接受度高，推进结账意愿强 |
| 14-19 | 存在一定支付意愿，但价格敏感明显 | 需要一定激励才转化，价格异议偏多 |
| 8-13 | 支付意愿弱或依赖强激励 | 高度依赖折扣 / 赠品才成交 |
| 0-7 | 缺少清晰支付意愿 | 认同价值但不愿付费 |

### 2.3 产品体验满意度（30 分，权重 30%）

| 得分档 | 定性判断 | 参考观察信号 |
|------|----------|------|
| 24-30 | 早期体验反馈稳定正向 | Beta / 早期买家反馈正向，复购与推荐意向明确 |
| 17-23 | 总体反馈正向，但存在明显改进项 | 满意为主，伴随集中的改进诉求 |
| 9-16 | 反馈分化较大 | 好评与差评并存，体验不稳定 |
| 0-8 | 负向反馈占主导或复购意愿不足 | 退货 / 投诉性质偏严重，复购意向低 |

### 2.4 竞争空间（20 分，权重 20%）

| 得分档 | 定性判断 | 参考观察信号 |
|------|----------|------|
| 16-20 | 存在清晰的差异化切口与未满足需求 | 竞品未覆盖的需求缺口明确，差异化可辩护 |
| 11-15 | 有一定差异化空间，但竞争并不轻 | 差异化存在但易被模仿 |
| 6-10 | 竞争拥挤，差异化较弱 | 同质化明显，需靠执行取胜 |
| 0-5 | 市场已高度同质化，缺少明确切口 | 红海且无差异化立足点 |

## 三、PMF 信号强度判定

```text
综合得分 → 信号强度 → 决策建议：

├── 75-100 分 → 强 PMF 信号 → SCALE
│   行动：进入规模化阶段
│   ├── 每周预算增加 20-30%
│   ├── 扩展到新渠道
│   ├── 启动留存体系（由用户留存引擎介入）
│   └── 开始品牌建设（由品牌策略引擎介入）
│
├── 50-74 分 → 中等 PMF 信号 → OPTIMIZE
│   行动：继续测试，聚焦优化最弱维度
│   ├── 识别得分最低的 1-2 个维度
│   ├── 制定针对性改进方案
│   ├── 再测试 2 周后重新评估
│   └── 预算保持不变或小幅增加
│
├── 25-49 分 → 弱 PMF 信号 → PIVOT
│   行动：重新审视核心假设
│   ├── 是否需要调整目标受众？
│   ├── 是否需要调整价值主张？
│   ├── 是否需要调整价格策略？
│   └── 制定 Pivot 方案后重新启动 MVP 测试
│
└── 0-24 分 → 无 PMF 信号 → KILL or MAJOR PIVOT
    行动：停止广告投放，回到产品层面
    ├── 重新进行用户访谈
    ├── 评估是否需要根本性产品改变
    ├── 如果 3 次 Pivot 后仍无信号 → 建议放弃该产品
    └── 将学到的经验应用到下一个产品
```
